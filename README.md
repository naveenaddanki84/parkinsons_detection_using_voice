# Project README

## Early Detection of Parkinson's Disease through Machine Learning and Deep Learning Models

This project aims to develop an automated framework for early detection of Parkinson's Disease (PD) using speech-based biomarkers. By leveraging advanced machine learning (ML) and deep learning (DL) techniques, the system achieves accurate and non-invasive diagnosis, emphasizing accessibility and real-time usability.

### **Dataset Information**

The dataset used in this project can be downloaded from the following link:

**[Dataset Drive Link](https://drive.google.com/file/d/1dVTqT5N4OcoTVvnjoRubfXzsO5X4LmRP/view?usp=sharing)**

### **Key Features of the Dataset**
- Contains speech recordings from PD patients and healthy controls.
- Features extracted include acoustic, spectral, prosodic, and temporal speech characteristics.
- Preprocessed data includes normalization, noise reduction, and segmentation.

### **Project Overview**

#### **Objectives**
1. Develop machine learning models for PD detection.
2. Employ deep learning methods for analyzing spectrograms.
3. Implement a real-time classification framework.

#### **Methodologies**
- Feature-based ML models: Support Vector Machine (SVM), Random Forest (RF), LightGBM.
- Spectrogram-based CNNs using Inception V3.
- Real-time pipelines with predictive modeling.

### **How to Use**

1. Download the dataset using the link provided above.
2. Extract and preprocess the data as described in the preprocessing section of the documentation.
3. Follow the implementation steps outlined in the project documentation to train and evaluate the models.
4. Utilize the real-time framework for live classification using speech input.

### **Dependencies**
- Python 3.8+
- Required libraries:
  - OpenSMILE
  - Librosa
  - Parselmouth
  - TensorFlow/Keras
  - scikit-learn
